SAMY

Concept project for Samy Cosmetics focused on product presentation, integrating visual design, animations, and 3D experiences to create greater impact and user engagement.

Launch project

Proyect details

This project consists of the design and development of an interactive website for showcasing the Samy Creamy Liquid Lipstick, integrating 3D and augmented reality technologies. The platform allows users to view the product in a three-dimensional scene, change its shade through a color carousel, and see the transition with an animated rotation. Additionally, it includes an augmented reality module that enables users to virtually try on the selected lipstick shade on their lips in real time, providing an innovative and immersive experience.

MAIN TYPE

Mona sans

Mona is SAMY’s accent typeface, self-hosted within the project. It is used exclusively in the regular weight and appears in the featured titles of each product’s pop-up, adding a more personal, brand-driven character to the typographic system.

Montserrat

With weights ranging from Light to Semibold, Montserrat is SAMY’s primary typeface. This highly legible geometric sans serif is used throughout the interface—including buttons, labels, values and prices, and navigation text—providing the consistency and clarity needed for a cohesive user experience.
